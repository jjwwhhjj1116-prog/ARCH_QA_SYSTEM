오픈소스 스킬을 검수 알고리즘의 정답 근거로 사용하지 않는다. 도메인 근거는 확인된 원본·사용자 지침·검증된 계산이다.

## 설치한 글로벌 스킬

`C:/Users/user-owner/.codex/skills/` 아래에 프로젝트 특화 SKILL.md 3개를 설치하고 공식 quick_validate를 각각 통과했다. 외부 소스를 복제한 패키지가 아니라 이번 업무의 안전·검증 원칙을 정리한 짧은 전용 지침이다.

1. **fin-source-mapping**: 원본·열 의미·단위·범위, 빈칸/0 구분, 동별집계표 공종 문맥, 원본 계보, 과도한 파일 팽창 방어.
2. **fin-rule-evidence**: 비교집단·조건/예외·ABC 판단, 동일 공종 강제 금지, 버전/불변 이력/사람 판단, 저장 시점 권한과 성능 검증.
3. **qc-workstation-delivery**: 좌측 프로젝트, 상단 주 행동, 검수표/근거 동기화, 한국어 가독성·키보드·실제 브라우저, 승인된 비공개 배포 확인.

적용 순서는 원본 매핑 → 규칙/근거 → 작업화면/인도다. Codex 새 작업에서도 전역 스킬로 발견할 수 있다. 자동 선택은 새 세션의 스킬 목록 갱신 후 적용되며 설치가 대화 기억이나 Mem0 연동을 대신하지 않는다.

## 후속 단계

- 실제 FIN 출력물별 정답 매핑과 오류를 주입한 회귀자료 확보. 임계값은 담당자가 승인한다.
- 동별집계표 동의어/오타/다국어 후보와 공종사전 추가. Gemini 결과는 원본 근거가 있는 C 후보로만 노출.
- 층고/층수/환산/개소 기준정보와 교차검수; 수정 전후 행 대응; 대규모 비동기 실행.
- 마감 분석표의 확정 입력/출력 샘플 대조. RC·조적은 별도 확정 후 착수.
